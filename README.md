![Licens: MIT](https://img.shields.io/badge/license-MIT-green)

__Great Cut__ is an online booking system for barber services.Customers browse services and barbers, pick an open time and book an appointment in seconds. Barbers manage schedules, availability and bookings from one dashboard.

**Live site** | https://wambua7.github.io/Great-Cut/

## The problem we're solving

> "Our customers call to book but we are busy cutting hair, so calls go unattended. Customers walk in and find a long queue waiting for their cut which turns them to the door.Meanwhile later on the barbershop is maybe empty or few clients.We keeep bookings in our diary and end up maybe double booking every week " - **Joseph ,owner, Great Cut Kilimani**

## Features

**For customers**
1. Browse __Services__ and view prices in KES.
2. Browse **barbers** and their specialities.
3. Click on a service and book a chair.

**For Barbershop**
- __Dashboard__ with today's stats,schedules (status badges),weekly availability and an update hours form.

**Everywhere** 
- Mobile-first responsive system.
- Dark mode toggle (remembers your choice)

code .

3.In vs code right click on the index.html and choose open wit live server
